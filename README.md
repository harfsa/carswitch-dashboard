# CarSwitch Dashboard — Daily Data Update

هذه النسخة تفصل بين **المنصة** و **مصدر البيانات**:

`CarSwitch → GitHub Actions يوميًا → data/carswitch_data.json → Dashboard`

## ماذا يحدث تلقائيًا؟

- تشغيل تحديث يومي الساعة **05:00 صباحًا بتوقيت السعودية**.
- اكتشاف إعلانات السيارات الفاخرة من CarSwitch KSA.
- إعادة فحص الإعلانات الموجودة.
- تحديث السنة / الممشى / السعر عند توفرها.
- حذف الإعلان فقط عند التأكد من أنه لم يعد إعلانًا حيًا.
- الاحتفاظ مؤقتًا بالإعلان عند حدوث خطأ اتصال عابر حتى لا تختفي البيانات بسبب عطل مؤقت.
- Commit تلقائي للبيانات الجديدة.
- نشر لوحة HTML تلقائيًا عبر GitHub Pages.
- زر «تحديث البيانات» داخل المنصة يجلب آخر ملف منشور فورًا.
- عند بقاء المنصة مفتوحة، يتم فحص المصدر كل 30 دقيقة.

## النشر

1. أنشئ Repository جديد على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى الفرع `main`.
3. من Settings → Pages اختر **GitHub Actions** كمصدر النشر.
4. شغّل workflow `Deploy CarSwitch dashboard` مرة واحدة.
5. شغّل `Update CarSwitch data` يدويًا أول مرة من تبويب Actions للتأكد من أن الـscraper يعمل.

بعد ذلك يكون رابط المنصة ثابتًا، وتُحدّث البيانات في الخلفية يوميًا.

## ملاحظة مهمة

الـHTML وحده لا يستطيع تشغيل scraper يوميًا عندما تكون الصفحة مغلقة. لهذا السبب التحديث اليومي موجود في GitHub Actions، بينما المنصة نفسها تستهلك ملف البيانات المنشور.
